# ChildLife Emergency Data Analytics - Patient Flow & Resource Optimization

**Inspired by 2 years experience as Data Analyst at ChildLife Foundation, Pakistan's largest pediatric emergency network.**

## Overview
Analyzed 50,000+ synthetic emergency records mimicking ChildLife ER data to optimize resource allocation and reduce patient waiting time.

## Key Analyses
1. Peak Hours Analysis - Identified 19:00-23:00 as busiest period
2. Disease Distribution - Pneumonia 22%, Diarrhea 18% as top causes
3. Staff vs Waiting Time Correlation - Negative correlation proved
4. Day-wise Load - Friday highest load (weekend effect)
5. Age-Disease Stacked Analysis

## Tools Used
Python, Pandas, Numpy, Matplotlib, Seaborn, Plotly

## Key Insight & Recommendation
**Finding:** Strong negative correlation (-0.42) between staff on duty and waiting time.
**Recommendation:** Increase staff by 20% during Friday night shifts to reduce average waiting time by 35% (from 45 min to 29 min).

## Impact
Demonstrates ability to handle large-scale healthcare data and provide actionable operational insights - core skill for MSc Data Science at University of Padua (Health Data Science track).
